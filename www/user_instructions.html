Requirements

  • The file format is restricted to .csv, .tsv and single sheet .xlsx.
  • The data has to be structured in a stacked format (see template).
  • The file must contain columns with the following information: concentration levels, concentration of solutions and peak areas. Column names can be freely chosen. It is not necessary to use the same names as in the example file.

Import

  1. In the "Import Data" tab, enter your data file.

  2. In the next steps, specify the columns that contain the corresponding data.

  3. Confirm your entries and start the calculations by pressing the "Calculate" button.

Results

  1. The calculated results can be viewed in the "Results" section under the corresponding tab.

  2. Change settings of the "Fitted Line Plot" by clicking on the bar chart icon in the top-right corner of the box.


    • Title: is displayed above the "Fitted Line Plot", as a title in the "Assay Results" table and in the left corner of the report header. If left blank, "Linearity Report" is displayed in the report header.
    • X-axis label, Y-axis label: are displayed in the "Fitted Line Plot" and are used as column headers in the "Assay Results" table for the corresponding column.
    • Reference concentration: is displayed in the "Fitted Line Plot", provided it is not 0. If reference concentration is provided, the intercept and the residual standard deviation in the "Linear Regression Results" table are expressed as a percentage of the analytical signal at a target or reference concentration (e.g. 100% working concentration for assay determinations or specification limit concentration for impurities determinations)
    • % of declared content: is the corresponding concentration level to the reference concentration e.g. for 100% working concentration enter 100 or if your concentration at the specification limit corresponds to 0.17% enter 0.17.
    • Update Plot: is used to update the plot with the values entered above.
    • Reset Input: is used to resets all inputs in the plot settings to their default values. The plot is not automatically updated by pressing the "Reset Input" button. To confirm the reset, press the "Update Plot" button afterwards.

Report

  1. Finally, the results can be downloaded in tabular form in the "Download Report" tab.

  2. Enter a file name, choose a document format and tick the boxes for all results and plots to be included in the report.

  3. Confirm your entries and download the report by pressing the "Generate Report" button.
