Requirements

  • The file format is restricted to .csv, .tsv and single sheet .xlsx.
  • The data has to be structured in a stacked format (see template).
  • The file must contain columns with the following information: concentration levels, concentration of solutions and peak areas. Column names can be freely chosen. It is not necessary to use the same names as in the example file.

Template Download


  1. Click on plus to open “User Instructions” section.
  2. Download a template file from the links and replace data with your own.

Data Import


  1. Click “Data Import” in the sidebar.
  2. Upload your data file in the “Import settings” box.

Import Details


  1. Select columns that contain corresponding data.
  2. Press the "Calculate" button to confirm your entries and start the calculations.

Imported Data Review


  1. Review the data in tabular form.

Results


  1. Click “Developing Unit” in the sidebar.
  2. Review results of linear regression.
  3. Click bar chart icon to customize fitted line plot.

  1. Enter a title. The title is displayed above the "Fitted Line Plot", as a title in the "Assay Results" table and in the left corner of the report header. If left blank, "Linearity Report" is displayed in the report header.
  2. Enter a x-axis label. X-axis label is displayed in the "Fitted Line Plot" and is used as column header in the "Assay Results" table for the corresponding column.
  3. Enter a y-axis label. Y-axis label is displayed in the "Fitted Line Plot" and is used as column header in the "Assay Results" table for the corresponding column.
  4. Enter a reference concentration. The reference concentration is displayed in the "Fitted Line Plot", provided it is not 0. If reference concentration is provided, the intercept and the residual standard deviation in the "Linear Regression Results" table are expressed as a percentage of the analytical signal at a target or reference concentration (e.g. 100% working concentration for assay determinations or specification limit concentration for impurities determinations)
  5. Enter a % of declared content. % of declared contentis the corresponding concentration level to the reference concentration e.g. for 100% working concentration enter 100 or if your concentration at the specification limit corresponds to 0.17% enter 0.17.
  6. Click “Update Plot” button to confirm entries.
  7. Click “Reset Inputs” button to set input fields back to default. The plot is not automatically updated by pressing the "Reset Input" button. To confirm the reset, press the "Update Plot" button afterwards.

Report download


  1. Click “Download Report” in the sidebar..

  1. Enter a file name.
  2. Choose a document format.
  3. Tick the boxes for all the results and plots to be included in the report.
  4. Press the "Generate Report" button to confirm your entries and download the report.
